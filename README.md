# FUTURE_ML_03
## Machine Learning Algorithm
* TF-IDF Vectorization + Cosine Similarity
## Technologies Used
* Python
* Pandas
* NLTK
* Scikit-learn
* Jupyter Notebook / Google Colab
## Features
* Resume text cleaning and preprocessing
* Skill extraction using NLP
* Job description analysis
* Resume-to-job matching
* Candidate ranking and skill gap identification
## Dataset
Dataset Name:Resume Screening System
Source:https://www.kaggle.com/datasets/snehaanbhawal/resume-dataset
## Project Workflow 
* Load Resume Dataset.
* Text Cleaning & Preprocessing.
* Skill Extraction.
* TF-IDF Vectorization.
* Job Description Input.
* Cosine Similarity Calculation.
* Resume Scoring.
* Candidate Ranking.
* Skill Gap Analysis.
* Final Output.
## Output
* Automatically ranks candidates based on job-role suitability and identifies missing skills.
## Conclusion
* The Resume Screening System helps recruiters quickly identify the most suitable candidates and reduces manual screening effort.
